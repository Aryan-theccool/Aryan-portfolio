## 📞 Quick Troubleshooting

**3D particles not showing?**
- Ensure WebGL is supported (modern browsers support this)
- Check that Three.js CDN is accessible

**Typography looks wrong?**
- Clear browser cache
- Ensure Plus Jakarta Sans and JetBrains Mono fonts load from Google Fonts

**Vignettes not visible?**
- Check scroll position (they appear bottom-left)
- Ensure JavaScript is enabled
